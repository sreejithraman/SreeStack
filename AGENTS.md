# SreeStack

This repo is the source of truth for user skills. Edit them here, not in live
skill folders. Built-in and plugin-managed skills stay with their hosts.

- Keep `skills/` flat. Keep repo-wide source records outside it in
  [SOURCES.md](SOURCES.md), following that file's format and invocation rules.
- Before modifying a skill, read its entry in `SOURCES.md` for source history,
  local adaptations, and invocation choices.
- Upstream updates must preserve local adaptations and invocation choices
  unless the user asks to change them. The recorded revision is the import
  baseline, not the latest version checked.
- Use [README.md](README.md) for repo purpose, setup, and credits to skill authors
  and projects. Keep full source records, including API docs and technical
  references, in `SOURCES.md`.
