# Security reports

Report a security issue through
[GitHub’s private reporting form](https://github.com/sreejithraman/SreeStack/security/advisories/new).
Include the affected skill or file, steps to reproduce, and the impact.
Keep credentials and other private data out of public issues.

For ordinary bugs and skill suggestions, use
[GitHub Issues](https://github.com/sreejithraman/SreeStack/issues).
