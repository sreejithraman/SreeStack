# Exhaust the Design Space

For a novel interaction or unresolved architecture tradeoff, compare meaningfully
different designs against the same requirements and criteria. Try enough options
to expose the decision; use a single experiment when testing one concrete claim
and additional candidates when they answer distinct questions. Use an interactive
prototype for UI feel and a disposable technical experiment for compatibility,
state, concurrency, or performance assumptions. Compare independent attempts
against shared criteria before synthesizing a consequential design. Existing
precedents can settle routine decisions.
