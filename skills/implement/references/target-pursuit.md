# Hard-target pursuit

Read this when pursuing a measurable target (performance, pass rate, accuracy, size) until it is met.

- **Keep the target fixed.** Never relax the predicate to declare victory. Measure through
  [acceptance guidance](../../reframe/references/acceptance.md).
- **Run disciplined experiments.** Choose each attempt from what the previous one established; an
  equivalent retry is not a new attempt. Explore uncertain approaches reversibly, and reach for
  original inputs, stronger instruments, or cross-field methods when local tweaks stall.
- **Keep wins, revert everything else.** Commit or keep verified improvements that advance the
  target without regressing required behavior. **Revert** attempts that fail, regress, or produce
  no measurable gain — never leave speculative changes riding along.
- **Suspect easy passes.** When a result jumps unexpectedly or passes too easily, verify the
  measurement harness and real product behavior before trusting the number.
- **Escalate real limits.** When evidence shows a hard limit that requires a product or quality
  tradeoff, return it as a decision request rather than lowering the bar.
- **Stay resumable.** Record accepted progress, the remaining gap, and the next hypothesis where a
  resumed session can find them. Use native goal tracking or scheduled continuation only when the
  user explicitly asks and the host supports it.
