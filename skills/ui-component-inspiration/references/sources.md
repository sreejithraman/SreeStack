# Source registry

Use this as a set of leads, not a list of endorsements. Check live pages and terms on each run. Add or remove one row when the source set changes; do not copy full component lists here.

When selecting Forever Components, read [its manifest search guide](forever-components.md).
When selecting Kinetics, read [its live search guide](kinetics.md).
Load only the guide for the chosen source.

## Copy-and-fit catalogs

| Source | Start page | Best fit | Watch |
| --- | --- | --- | --- |
| React Bits | https://reactbits.dev | Animated text, backgrounds, cards, and playful effects | React-focused. The public repo uses MIT terms with a Commons Clause; check the current file before copying or shipping a component pack. |
| Magic UI | https://magicui.design/docs/components | Marketing pages, product reveals, data displays, and small moments of delight | React and Tailwind. Many parts are open source, while paid templates sit beside them. |
| Lightswind UI | https://lightswind.com/components | A wide mix of core controls, AI screens, effects, and full page sections | Free and paid work may sit together. Check packages and the exact item's terms. |
| Aceternity UI | https://ui.aceternity.com/components | High-impact landing pages, cards, backgrounds, text, and 3D effects | Free components, paid blocks, and templates share the site. Effects can carry more code and motion than a product screen needs. |
| Hover.dev | https://www.hover.dev/components | Full sections plus cards, forms, menus, loaders, and 3D pieces | Free and paid access may differ by item. Check the exact page and terms. |

## Pattern banks

| Source | Start page | Best fit | Watch |
| --- | --- | --- | --- |
| Forever Components | https://forevercomponents.com/infinite/ | Raw HTML, CSS, and JavaScript studies for uncommon visual effects | Treat examples as mechanics to study. Check origin and terms before a direct port. |

## Tools, not component catalogs

| Source | Start page | Use only when | Watch |
| --- | --- | --- | --- |
| Motion | https://motion.dev/docs/react | A pick needs a gesture, layout change, scroll link, or interruptible animation and the stack can take the tool | Prefer the repo's current motion tool. Docs and examples do not make a ready-made product component. |
| Superdesign | https://superdesign.dev | The user wants a new design study or prompt-led screen draft rather than a known component | It is a design agent, not a component catalog. Its repo mixes AGPL and paid files, so review file terms before code use. |

## Search language

Search by a mix of:

- role: hero, empty state, command menu, data card, timeline, toast, upload, compare;
- action: reveal, select, drag, sort, confirm, load, filter, switch;
- feel: calm, tactile, dense, playful, sharp, soft, spatial;
- mechanic: parallax, glare, mask, morph, beam, stagger, spring, shader.

The same mechanic with a new brand name is one pattern group.
