# Kinetics

Use this guide when searching Kinetics for motion patterns.

1. Open [Kinetics](https://kinetics.colorion.co) and search by interaction,
   interface role, and motion character. Judge the examples against the
   request; vary the wording when results are weak.
2. If the page omits code or is hard to search, inspect the current
   [official repository](https://github.com/ckissi/kinetics).
   Locate its search index and example source; prior layouts used
   `public/js/search-index.js` and `src/content/body.html`.
   Confirm the paths in the current tree before fetching them.
3. Read each leading example's parameters, description, CSS, React, and
   prompt where present. Follow any referenced styles or scripts that drive
   the effect. When using repository files, keep them at one commit and
   record that revision with the source link.
4. Return to the shared source-code checks and shortlist. Name the effect,
   link its page and inspected source, and explain the useful mechanic.
   Distinguish an example seen on the live site from one found only in the
   repository.
